# Scrobble Bridge 1.0.0

## English

- Syncs YouTube Music listening history to Last.fm from a local-first background desktop App.
- Uses the Chrome extension to refresh YouTube Music access without storing credentials in the repository or diagnostics.
- Provides Last.fm account authorization, resilient retry/outbox handling, sync history, pause/resume controls, and privacy-safe diagnostics.
- Checks for software updates once a day. When an update is available, the home screen lets you download it, verify its signature, and choose **Update now and restart**; updates are never silently installed.
- Runtime-tested on Apple silicon macOS. The Intel Mac package is Beta and has not been tested on Intel hardware.
- Windows and Docker/NAS support are Experimental and have not received platform runtime testing. The Windows installer is unsigned.

## 简体中文

- 通过本地优先的后台桌面 App，将 YouTube Music 收听历史同步到 Last.fm。
- 使用 Chrome 扩展刷新 YouTube Music 访问状态，不在仓库或诊断信息中保存凭据。
- 提供 Last.fm 账号授权、可靠的重试与 outbox、同步历史、暂停/继续以及隐私安全的诊断导出。
- 每天自动检查一次软件更新。发现更新后，主页会让用户主动下载、验证签名，再选择“立即更新并重启”；不会静默安装。
- 已在 Apple Silicon macOS 上完成运行测试。Intel Mac 安装包为 Beta，尚未在 Intel 硬件上测试。
- Windows 和 Docker/NAS 支持均为 Experimental（实验性版本），尚未做对应平台的运行测试；Windows 安装程序未签名。
