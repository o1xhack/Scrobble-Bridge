# Scrobble Bridge 1.0 QA 报告

日期：2026-08-25（America/Los_Angeles）

本文只记录公开仓库可分享的功能验证，不包含实际 YouTube Music / Last.fm 账号、私人收听历史、应用密钥、Cookie、session、系统用户名或本机绝对路径。

## 交付范围

- YouTube Music → Last.fm 本地优先同步；桌面 App、Chrome 扩展和 Docker/NAS 共用 Rust 同步核心。
- 官方桌面构建支持维护者提供的 Last.fm API application；普通用户只需在 Last.fm 登录授权。未配置维护者凭据的源码构建和 NAS 保留自备 API application 路径。
- 不提供厂商账户系统、云端 Cookie 中转、订阅服务或自动导入全部历史记录。

## 自动化验证覆盖

### 初始化与 Last.fm 授权

- 首次启动可将成对提供的项目级 Last.fm API Key / Shared Secret 导入系统凭据库。
- GitHub Actions 仓库已配置对应的两项项目级加密 Secret；公开源码、文档与日志不包含实际凭据。
- 已存在的用户自备 API application 不会被官方默认凭据覆盖。
- 空白或只提供一项的应用凭据会 fail closed，不生成半完成配置。
- 用户在浏览器批准 Last.fm 后切回桌面 App 时自动尝试完成授权；保留手动完成按钮用于恢复。
- Last.fm 无效 session、撤销授权和认证错误进入明确的重新授权状态。
- 重新授权后，之前因为 `lastfm_auth` 被延迟的 scrobble 会立即重新进入待处理队列，不必等待原来的 24 小时退避；其他错误的重试时间保持不变。

### YouTube Music 与 Chrome

- 支持三种运行端认可的 SAPISID Cookie 变体；缺失、过期、HTTP 401 / 403 或无效 delegated-account 上下文进入可操作的重新登录状态。
- Chrome 只对 YouTube 域名上的明确认证 Cookie 变化触发刷新，不响应外观相似的第三方域名或无关 Cookie。
- Google 多账号序号、delegated/brand account、空账号信息、越界序号和损坏的账号 ID 均有 fail-closed 覆盖。
- 安装时不申请 YouTube 站点访问；Cookie、YouTube Music 与父域权限按需请求，NAS 只申请用户指定的 HTTPS origin。
- Chrome 关闭后继续使用上一次有效登录快照；关闭期间无法主动刷新已经失效的 Cookie。
- 商店 ZIP 自动移除开发环境固定公钥，同时保留本地开发扩展的稳定 ID 和 Native Messaging 连接。

### 后台恢复、幂等与异常

- 首次历史窗口只建立 baseline，不回填旧播放。
- 新播放按确定性 fingerprint 去重，连续播放、窗口内部迟到插入和有限历史变化按同步算法处理。
- 进程在 Last.fm 提交过程中被中断后，重启会重新检查 Last.fm recent tracks，不盲目重复提交。
- 无法安全对齐的历史窗口不会覆盖最后一个安全 baseline，也不会假装同步成功；后台仍会在后续周期继续尝试。
- 单首被拒绝的歌曲不会永久阻断之后的新播放。
- 网络断开、Last.fm HTTP 429、HTTP 503 和可恢复上游错误进入定时重试；Cookie 失效、用户授权失效和未知 YouTube 历史格式不会无限重试。
- 同步依赖未配置或账号上下文损坏时不会卡在 `syncing`。
- 正常计时器延迟不会误报睡眠；超过阈值的长时间系统暂停/唤醒触发补跑。macOS 睡眠期间即使单调时钟停止，也通过系统墙上时钟识别唤醒；系统时间向后调整不会误报，MissedTickBehavior 使用 `Skip` 避免补跑风暴。
- 用户主动暂停在应用重新启动后保持；未配置和暂停的运行端不会被后台调度器启动。

### 存储与隐私

- SQLite outbox 保留 pending / retryable / accepted / rejected 状态，并对重启中断进行恢复。
- 桌面凭据只进入 macOS Keychain / Windows Credential Manager；NAS 凭据使用单独 master key 加密保存。
- 原始 Cookie 不进入 Chrome 扩展持久化存储、诊断导出、Git 源码或公开 QA 证据。
- NAS pairing 使用一次性配对码、HTTPS、时间窗口、HMAC 签名和持久化 nonce 防重放。
- 历史内部截图和真实账号测试资料不纳入公开仓库。

## 真实环境证据与边界

此前的 macOS 安装版已经完成真实 YouTube Music 登录、Chrome Native Messaging 凭据刷新、Last.fm 账号授权、真实 scrobble 接受以及同一历史窗口幂等重跑。本公开报告只描述结果，不记录账号名称、歌曲标题或个人收听轨迹。
